# Data Analytics Portfolio

A collection of data analytics projects, from data cleaning and analysis to visualization and insights.

## Projects

### [Global Sales Analysis](./sales-1246-orders)
Google Sheets analysis of 1,246 orders across 45 countries and 12 product categories, 2010 to 2017. Uses XLOOKUP, SUMIFS, ARRAYFORMULA, pivot tables, and an interactive mini dashboard with slicers.

### [Netflix Content Dashboard](./netflix-dashboard)
Tableau dashboard analyzing the Netflix catalog, around 8,780 titles. Covers content type distribution, ratings, genres, countries, and growth over time.

## Tools

Google Sheets, Tableau, SQL (in progress)
